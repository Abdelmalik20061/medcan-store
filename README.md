# Medcan Store

نظام إدارة المتجر — نسخة الويب.

تطبيق صفحة واحدة يعمل بالكامل في المتصفح: قاعدة بيانات SQLite مُجمَّعة إلى
WebAssembly، وكل البيانات محفوظة محلياً في متصفح الجهاز.

- `index.html` — التطبيق كاملاً في ملف واحد. لا يحتاج خادماً أو قاعدة بيانات.
- نسخة سطح المكتب لويندوز هي نسخة التشغيل الفعلية.

## النشر

الملف `index.html` مكتفٍ ذاتياً: أي استضافة ملفات ثابتة تكفي.

- **GitHub Pages** (مُفعّلة حالياً): https://abdelmalik20061.github.io/medcan-store/
- **Vercel**: استورد هذا المستودع من https://vercel.com/new — لا يحتاج أي إعداد
  أو أوامر بناء. ملف `vercel.json` يمنع التخزين المؤقت حتى تظهر التحديثات فوراً.
